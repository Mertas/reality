# Reality — «Это вода» · интерактивное исследование

Один вопрос: *может ли существовать истина о природе реальности — настолько очевидная, настолько всеобъемлющая, настолько вездесущая, что её невозможно заметить, даже постоянно глядя прямо на неё?*

Проект превращает материалы расследования (эссе + отчёты семи исследовательских агентов) в интерактивный сайт: пять слоёв с живыми демонстрациями, карточки кандидатов, четыре маршрута «поимки» невидимого, линии скепсиса — и практика на каждый день с дневником.

## Стек

- **Vite 6 + React 18 + TypeScript (strict)**, npm. Без бэкенда, без внешних сервисов и CDN — работает офлайн.
- Дизайн-система — CSS-токены в `src/styles/global.css`; стили модулей — `demos.css`, `practice.css`.
- Состояние: контекст приложения (`src/state/app.tsx`) + localStorage (`reality.progress.v1`, `reality.practice.v1`).

## Запуск

```
npm install          # один раз
npm run dev          # dev-сервер на http://localhost:1836
npm run build        # статическая сборка в dist/
npm run preview      # просмотр сборки
npm run typecheck    # проверка типов
```

Двойной клик по **`Reality.bat`** — запускает dev-сервер и открывает браузер.

## Главы

0. **Вода** — зачем это всё и как читать.
1. **Почти теорема** — пять слоёв невидимости с демо (Трокслер, слепое пятно, контраст, разрез фон Неймана).
2. **Жильцы ниши** — кандидаты: сознание, бытие, «сейчас», пустота, разрез наблюдателя.
3. **Как берут невидимое** — четыре маршрута (нети нети, «по работе», «посмотри на смотрящего», горилла).
4. **Где всё ломается** — скепсис и итог.
5. **Практика** — вода дня, чек-лист, серии дней, дневник, экспорт.
6. **Источники** — дословности/парафразы и архив отчётов агентов.

## Контент и честность

- Весь контент — в `src/data/content.ts`; правки — только там, сверяясь с `docs/essay.md`.
- Каждая цитата помечена: **дословно** или **парафраз** (глава «Источники», `docs/agents/*`).
- Сайт не утверждает, что «такая истина существует»; он показывает, почему вопрос устроен так, что ответ нельзя предъявить как факт.

## Как это собиралось

- **7 исследовательских агентов** — философские отчёты (`docs/agents/`).
- **Ванильная сборка** — 3 агента (демо, контент, практика) → сохранена в `legacy/vanilla` как источник переноса.
- **React-перенос** — агенты D (демо) и E (практика) + QA-агент.
- Контракты и процессы: `docs/CONTRACTS.md`, `docs/PORT-CONTRACTS.md`, `docs/PLAN.md`, `docs/QA-CHECKLIST.md`.

## Приватность

Прогресс и дневник — только в localStorage браузера; ничего не отправляется в сеть.
