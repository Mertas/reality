- [ ] `gorilla`: полный раунд (счёт передач, горилла, два вопроса, результат с числами 46%/88, повтор 0.6× с подсказкой).

- [ ] `looking`: 90 секунд, смена строк, досрочное завершение, заметка → «сохранить в дневник» (или вежливая подсказка).
- [ ] `contrast`: при контрасте 0 фигура исчезает.
- [ ] `cut`: слайдер двигает разрез, подписи меняются.
- [ ] Два экземпляра одного демо не конфликтуют (проверить в тестовом окружении или по коду).
- [ ] Ни одно демо не бросает ошибок; у каждого слота заголовок и подпись.
